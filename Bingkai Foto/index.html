Bingkai Foto

Ulasan
Tombol keyboard yang sudah tidak terpakai dapat ditempelkan pada bingkai foto untuk menciptakan hiasan unik bertema teknologi. Produk ini cocok sebagai hadiah atau dekorasi meja.

Alat dan Bahan:

  • Gunting
  • Penggaris
  • Pensil
  • Lem tembak
  • Tombol keyboard bekas
  • Bingkai foto sederhana
  • Kardus tebal
  • Kertas warna

Langkah Pembuatan:

  1. Kumpulkan tombol keyboard yang masih bersih.
  2. Bersihkan tombol dan keringkan.
  3. Siapkan bingkai foto bekas atau bingkai sederhana.
  4. Atur tombol di sekeliling bingkai sebelum direkatkan.
  5. Tempel tombol satu per satu menggunakan lem.
  6. Tambahkan kertas warna untuk mempercantik bagian belakang.
  7. Masukkan foto ke dalam bingkai.
  8. Periksa kekuatan tempelan sebelum produk digunakan.
